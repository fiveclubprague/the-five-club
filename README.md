# THE FIVE CLUB — site vitrine

Site statique (HTML / CSS / JS, aucune dépendance à installer). Bilingue EN / CS.

## Structure
- `index.html` : toute la page (styles et scripts inclus)
- `img/` : photos du site

## Tester en local
Ouvre `index.html` dans un navigateur, ou lance `python3 -m http.server` dans le dossier.

## Mettre en ligne (GitHub Pages)
1. Pousse ces fichiers à la racine d'un dépôt GitHub.
2. Settings > Pages > Source : branche `main`, dossier `/ (root)`.
3. Plus tard, nom de domaine : Settings > Pages > Custom domain, puis configure le DNS chez ton registrar.
